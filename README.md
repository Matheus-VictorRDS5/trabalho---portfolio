# Portfólio · Fitas VHS

## Como abrir
Abra o `index.html` no navegador (precisa de internet: Three.js e a fonte VT323 vêm de CDN).
Se preferir um servidor local: `python3 -m http.server 8000` e acesse http://localhost:8000.

## PC 3D
O PC dos anos 90 é construído em código, na função `initGL` de `js/main.js`
(gabinete, monitor CRT, teclado e mouse). Cores e medidas podem ser ajustadas ali.

## Fitas
Edite `js/data.js`: copie um bloco de fita e troque o conteúdo.

## Fonte
Troque `--font` no topo de `css/style.css`.
